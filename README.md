# Chutipon Portfolio — Senior Enterprise Architecture 🚀

A breathtaking, high-performance creative portfolio website designed for a Computer Science university admission showcase. Built to completely bypass standard drag-and-drop site builders and replace them with an elite frontend engineering experience.

## ✨ Signature Features

- **Dynamic Cinematic Hero:** Staggered 3-word reveal with parallax scroll fades, canvas particles, and an animated aurora overlay.
- **The Architect Terminal:** A fully responsive macOS-style terminal simulation with fluid custom typing effects.
- **Fluid Continuity:** Global smooth-scroll injection integrated via Lenis provider.
- **Cursor-Tracked Bento Grid:** Fully asymmetric 3-column interactive layout driven by real-time cursor motion vectoring (3D Tilt & Glare).
- **Masterpiece Matrix:** Multi-axis layout transforming continuous vertical scroll into horizontal tracking, complete with custom YouTube lightbox portals.

## 🛠 Tech Stack

- **Framework:** Next.js 14 (App Router Architecture)
- **Animation Engine:** Framer Motion (useScroll, useTransform custom spring vectors)
- **Styling Core:** Tailwind CSS (Fluid utility layers & Dynamic custom tokens)
- **Primitives:** Radix UI / Lucide React
- **Hosting Platform:** Vercel Infrastructure

## 🚀 Local Initialization

```bash
# Install dependencies
npm install

# Boot development environment
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
